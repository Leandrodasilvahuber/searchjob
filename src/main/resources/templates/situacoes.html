Situações e perguntas aprendidas

Cada linha é uma regra que o robô usa quando encontra uma pergunta igual ou muito parecida num formulário.

Resposta pronta

O texto salvo vai direto para o campo do formulário, sem chamar a IA. Ex.: “Sim”, “7.000”, “Linkedin”.

Instrução pra IA

O texto salvo não vai para o formulário. É o pedido que a IA recebe para escrever uma resposta nova para cada vaga, com base no currículo. O que ela escreveu fica em Textos da IA.
